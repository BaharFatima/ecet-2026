01 Algorithms & Flowcharts ▶
Algorithm

An algorithm is a finite set of well-defined, step-by-step instructions to solve a problem. It must be: Input, Output, Definiteness, Finiteness, Effectiveness.

Key Properties (IODFE) Input – zero or more inputs | Output – at least one output | Definiteness – unambiguous steps | Finiteness – terminates in finite steps | Effectiveness – each step is basic/feasible

Example – Find largest of 3 numbers:

Step 1: Start
Step 2: Read A, B, C
Step 3: If A > B and A > C then Large = A
         Else if B > C then Large = B
         Else Large = C
Step 4: Print Large
Step 5: Stop

Exam TipDecision box has TWO exits (YES/NO). Terminal box used exactly TWICE (start & stop).

04 Type Conversion & Preprocessor Directives ▶
Type Conversion

Implicit (Automatic): Compiler converts lower type to higher automatically in mixed expressions.

// Hierarchy: char → int → long → float → double → long double
int a = 5;
float b = 2.5;
float c = a + b;  // a is promoted to float → c = 7.5

Explicit (Type Casting): Programmer forces conversion using (type)

int a = 7, b = 2;
float c = (float)a / b;  // c = 3.5 (NOT 3)
// Without cast: 7/2 = 3 (integer division)
Common Mistakeint/int = int (not float). Always cast if you want decimal result!
Preprocessor Directives

Preprocessor directives are processed BEFORE compilation. They start with #.

DirectivePurposeExample
#includeInclude header files#include <stdio.h>
#defineDefine macro/constant#define PI 3.14
#undefRemove a macro#undef PI
#ifdefIf macro is defined#ifdef DEBUG
#ifndefIf macro NOT defined#ifndef PI
#if / #else / #endifConditional compilation#if X > 0
#pragmaCompiler-specific instructions#pragma once
Key Facts • #define PI 3.14 → no semicolon! It's text replacement.
• <stdio.h> for printf/scanf | <string.h> for string functions | <math.h> for maths
• #include <file> searches system path | #include "file" searches current directory first

05 Decision Making & Looping Statements ▶
Decision Making
// if-else if-else ladder
if (condition1) { ... }
else if (condition2) { ... }
else { ... }

// switch-case (for integer/char constants only)
switch(expr) {
  case 1: ...; break;
  case 2: ...; break;
  default: ...;
}
Switch Rules • switch expression must be integer or char (NOT float/string)
• Without break, execution falls through to next case
• default is optional but good practice
Looping Statements
LoopSyntaxWhen to UseCheck
forfor(init;cond;update)Known iterationsEntry
whilewhile(cond) {}Unknown iterationsEntry
do-whiledo {} while(cond);Execute at least onceExit
// for loop
for(int i=0; i<5; i++) { printf("%d ", i); }
// Output: 0 1 2 3 4

// do-while: runs at least ONCE even if condition false
int i = 10;
do { printf("%d", i); i++; } while(i < 5);
// Output: 10 (runs once)
break and continue
  • break – exits the innermost loop/switch immediately
  • continue – skips rest of current iteration, goes to next iteration
for(int i=1; i<=5; i++) {
  if(i==3) continue; // skips 3
  if(i==5) break;    // stops at 5
  printf("%d ", i);
}
// Output: 1 2 4

Static Variable Key Fact A static local variable retains its value between function calls. It is initialized only ONCE. 
void count() {
  static int n = 0;
  n++;
  printf("%d ", n);
}
count(); count(); count();
// Output: 1 2 3  (n retains value!)
register: Hint to compiler to store in CPU register for faster access. Cannot take address of register variable (& not allowed).
Recursion

A function calling itself is recursion. Every recursive function must have a base case to stop.

// Factorial using recursion
int factorial(int n) {
  if(n == 0 || n == 1) return 1;   // base case
  return n * factorial(n - 1);      // recursive call
}
// factorial(4) = 4*3*2*1 = 24

// Fibonacci
int fib(int n) {
  if(n<=1) return n;
  return fib(n-1) + fib(n-2);
}
Recursion vs Iteration Recursion uses STACK memory for each call. Without a base case → stack overflow (infinite recursion). Iteration is generally faster and uses less memory.

09 Structures & Unions ▶
Structures

A structure groups variables of different data types under one name.

struct Student {
  int rollno;
  char name[20];
  float marks;
};

struct Student s1;          // declare
s1.rollno = 101;            // access with dot (.)
strcpy(s1.name, "Ravi");

// Pointer to structure → use arrow (->)
struct Student *ptr = &s1;
ptr->rollno = 102;
Size of Structure Size = sum of sizes of all members (may include padding for alignment). Use sizeof() to get actual size.
Unions

All members of a union share the same memory location. Size = size of the LARGEST member.

union Data {
  int i;      // 4 bytes
  float f;    // 4 bytes
  char c;     // 1 byte
};
// sizeof(union Data) = 4 (largest member)
// Only ONE member can store valid data at a time!
FeatureStructureUnion
MemorySeparate for each memberShared by all members
SizeSum of all member sizesSize of largest member
AccessAll members simultaneouslyOnly one at a time
UseRecord keepingMemory saving
