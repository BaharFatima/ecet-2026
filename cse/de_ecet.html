Conversion Methods
Most asked in exams
Decimal → Binary
Divide by 2, collect remainders bottom-up.
13 → 1101₂
13÷2=6 R1, 6÷2=3 R0, 3÷2=1 R1, 1÷2=0 R1
Binary → Decimal
Multiply each bit by 2^position, add up.
1101 = 8+4+0+1 = 13
Binary → Octal
Group bits in 3s from right.
110 101 → 65₈
Binary → Hex
Group bits in 4s from right.
1010 1111 → AF₁₆
Exam Trick: Octal uses groups of 3 bits, Hex uses groups of 4 bits. Always group from the decimal point outward.

Gray Code key property: Only ONE bit changes between consecutive values — used in shaft encoders to prevent errors.
Excess-3 property: BCD + 0011. It is self-complementing: 9's complement of a digit = bitwise NOT of its XS3 code.
BCD vs Binary: BCD uses 4 bits per decimal digit. 99 in BCD = 1001 1001 (8 bits), but in binary = 1100011 (7 bits).
🧮
1's & 2's Complement
Used in arithmetic operations
1's Complement
Invert all bits.
1010 → 0101
2's Complement
1's complement + 1. Used for subtraction in digital circuits.
1010 → 0101 + 1 = 0110
Rule for 2's complement shortcut
Copy bits from right up to and including first 1, then invert rest.

Gate Properties & Tricks
AND
Output 1 only when ALL inputs are 1. "All must agree."
OR
Output 1 when ANY input is 1. "At least one."
NOT
Inverter. Single input. A̅
NAND
AND then invert. Universal gate. Can make AND/OR/NOT.
NOR
OR then invert. Universal gate. Can make AND/OR/NOT.
XOR
Output 1 when inputs are DIFFERENT. Used in adders & parity.
Universal Gates: NAND and NOR each alone can implement any Boolean function. This is a very common MCQ fact!
XOR identities: A⊕0=A, A⊕1=A̅, A⊕A=0, A⊕A̅=1. XOR with 1 = complement. XOR detects odd number of 1s.
🔄
Implementing Gates using NAND
GateNAND implementation
NOT ANAND(A,A)
A AND BNAND(NAND(A,B), NAND(A,B))
A OR BNAND(NAND(A,A), NAND(B,B))
Exam tip: Minimum NAND gates: NOT=1, AND=2, OR=3. NAND is cheaper in TTL fabrication.
Topic 03
Boolean Algebra & De Morgan's
Laws of Boolean algebra, SOP, POS forms, and De Morgan's theorems for simplification.
∧
Boolean Laws

Identity Laws

A + 0 = A
A · 1 = A

Null Laws

A + 1 = 1
A · 0 = 0

Complement Laws

A + A̅ = 1
A · A̅ = 0

Idempotent Laws

A + A = A
A · A = A

Commutative

A + B = B + A
A · B = B · A

Associative

(A+B)+C = A+(B+C)
(A·B)·C = A·(B·C)

Distributive

A·(B+C) = AB + AC
A+(B·C) = (A+B)·(A+C)

Absorption

A + AB = A
A(A+B) = A
🔁
De Morgan's Theorems
MOST important for MCQs
Theorem 1
(A · B)̄ = Ā + B̄
NAND = NOT of AND = OR of inverted inputs
Theorem 2
(A + B)̄ = Ā · B̄
NOR = NOT of OR = AND of inverted inputs
How to apply: Break the bar, change the operator (AND↔OR), invert each variable.
Dual principle: Any Boolean expression remains valid if you swap AND↔OR and 0↔1 simultaneously.
📝
SOP and POS Forms
SOP – Sum of Products
OR of AND terms. Each term called a minterm. Output = 1 for selected rows in truth table.

F = AB + AC̄ + BC

Canonical SOP uses all variables in each product term (minterms m₀, m₁...).
POS – Product of Sums
AND of OR terms. Each term called a maxterm. Output = 0 for selected rows.

F = (A+B)(Ā+C)

Canonical POS uses all variables in each sum term (maxterms M₀, M₁...).
Minterm vs Maxterm: mᵢ = complement of Mᵢ. F in minterms and F̄ in same minterms = F in remaining maxterms.
Exam shortcut: If F = Σm(1,3,5,7) then F = ΠM(0,2,4,6). They complement each other!

  • Groups must be powers of 2 only: 1, 2, 4, 8, 16
  • Groups wrap around edges (the K-map is toroidal)

  • Each 1 must be covered by at least one group
  • Use minimum number of groups
  • Don't Care (X): Can be grouped or not — use them to make larger groups
Variable in simplified term

If a variable appears as 1 in all cells → use variable (A)
If a variable appears as both 0 and 1 → ELIMINATE it
✅
Prime Implicants
Prime Implicant (PI)
A group that cannot be made larger while still covering only 1s.
Essential PI (EPI)
A PI that covers at least one minterm not covered by any other PI. EPIs MUST be in the final expression.
Exam rule: Always include all Essential Prime Implicants. Then cover remaining minterms with fewest additional PIs.

📊
Key IC Characteristics
Fan-out
Number of standard gate inputs that one output can reliably drive. CMOS > TTL.
Fan-in
Number of inputs to a gate. Increasing fan-in increases propagation delay.
Noise Margin
Tolerance to voltage noise. NM_H = VOH_min − VIH_min. NM_L = VIL_max − VOL_max.
Propagation Delay (tpd)
Time from input change to output change (50% points). Lower = faster.
Power-Delay Product
Figure of merit = Power × Delay. Lower is better. CMOS wins at low frequencies.
TTL Sub-families
Standard, Schottky (74S), Low-power Schottky (74LS), Advanced (74AS), FAST (74F).
CMOS unused inputs: Must NEVER be left floating. Connect to Vcc or GND to prevent latch-up.

Ripple Carry Adder: Chain of full adders where Cout of one connects to Cin of next. For n bits = n full adders. Disadvantage: Carry must ripple through all stages (slow).

Magnitude Comparator

Compares two binary numbers A and B. Outputs: A>B, A=B, A<B.

1-bit comparator
A=B: XNOR → A⊙B = (AB + Ā·B̄)
A>B: A·B̄
A<B: Ā·B

One input → many outputs. Select lines route the single input to one of the outputs.

Encoder
2ⁿ inputs → n outputs. Converts one-hot input to binary. Priority encoder: handles multiple simultaneous inputs (highest priority wins).

⏰
Edge vs Level Triggering
Level Triggered (Latch)
Output changes whenever clock is HIGH (or LOW). Transparent — changes propagate as long as clock is active. Prone to race conditions.
Edge Triggered (Flip-Flop)
Output changes only at rising edge (↑) or falling edge (↓) of clock. Much more reliable. Used in synchronous circuits.
Master-Slave JK: Uses two latches. Master captures on rising edge, slave transfers on falling edge. Eliminates race-around condition in JK FFs.
Race-around condition: In level-triggered JK with J=K=1, output oscillates multiple times during clock HIGH. Solution: use edge-triggering or master-slave.
📌
Preset & Clear (Asynchronous)

Most flip-flops have active-low Preset (PRE) and Clear (CLR) pins that work independently of the clock.

PRE=0 → Force Q=1 immediately (async)
CLR=0 → Force Q=0 immediately (async)
PRE=CLR=1 → Normal clocked operation

Registers
TypeAbbreviationDescription

Counters
Asynchronous (Ripple) Counter
FFs triggered by output of previous FF, not common clock. Simple but slow (propagation delay accumulates). n-bit = 2ⁿ states (modulo-2ⁿ).
Synchronous Counter
All FFs triggered by same clock. Faster, no cumulative delay. Can implement any count sequence (mod-N counters).

Flash ROM – Features & Applications

Key Characteristics

  • Non-volatile: Retains data without power
  • Block erase: Erased in sectors/blocks (not byte-by-byte like EEPROM)
  • Fast read: Similar to EPROM read speed
  • In-system programmable: Can be updated without removing chip
  • Wear leveling: Blocks have limited erase cycles (~100K–1M)

Applications

BIOS / UEFI firmware USB pen drives SD / microSD cards SSDs (Solid State Drives) Embedded system firmware Mobile phone OS storage Digital cameras MP3 players
NOR Flash
Random access possible. Faster read. Used for code storage (BIOS). Each cell connected in NOR configuration.
NAND Flash
Higher density, lower cost per bit. Sequential access. Used for data storage (SSDs, USB drives). Cells in NAND configuration.
Exam fact: Flash memory is faster to write than EEPROM (block operations). EEPROM is slower but can erase byte-by-byte. Both are non-volatile.
