📌 What is a Matrix?

A matrix is a rectangular array of numbers arranged in rows and columns. If a matrix has m rows and n columns it is called an m×n matrix. The number m×n is called its order. Each number in the matrix is called an element and is denoted aᵢⱼ where i = row number, j = column number.

Matrix TypeDefinitionKey Property
Row MatrixHas only 1 row (1×n)Like a row vector
Column MatrixHas only 1 column (n×1)Like a column vector
Square MatrixNumber of rows = number of columnsCan compute determinant
Diagonal MatrixAll elements except main diagonal are zeroaᵢⱼ=0 for i≠j
Identity (Unit) Matrix IDiagonal=1, rest=0AI = IA = A always
Null (Zero) Matrix OAll elements = 0A+O=A, AO=OA=O
Symmetric MatrixAᵀ = A (aᵢⱼ = aⱼᵢ)Elements mirror across diagonal
Skew-SymmetricAᵀ = −A (aᵢⱼ = −aⱼᵢ)All diagonal elements must be 0

📌 Matrix Operations

Transpose (Aᵀ): Rows become columns, columns become rows. If A is m×n, then Aᵀ is n×m.

Addition/Subtraction: Only matrices of the same order can be added. Add element-by-element. (A+B)ᵀ = Aᵀ+Bᵀ.

Scalar Multiplication: Each element is multiplied by the scalar k. d(kA)/dk = A (trivially).

Matrix Multiplication: A(m×n) × B(n×p) = C(m×p). The element cᵢⱼ = sum of products of row i of A with column j of B. Critical rule: number of columns of A must equal number of rows of B. Matrix multiplication is NOT commutative — AB ≠ BA in general. But it IS associative: A(BC)=(AB)C.

Properties of Transpose: (Aᵀ)ᵀ = A (A+B)ᵀ = Aᵀ + Bᵀ (AB)ᵀ = BᵀAᵀ ← order REVERSES! (kA)ᵀ = k·Aᵀ

📌 Determinants — Full Theory

The determinant is a special scalar value computed from a square matrix. It tells us whether the matrix has an inverse. Think of it as a "scaling factor" — if det=0, the matrix collapses space to lower dimension (no inverse). If det≠0, the matrix is invertible.

For 2×2 matrix A = [[a,b],[c,d]]
|A| = det(A) = ad − bc Example: |[[3,2],[1,4]]| = 3×4 − 2×1 = 12−2 = 10
For 3×3 matrix — Expansion along Row 1 (Laplace Expansion)
|A| = a₁₁·|M₁₁| − a₁₂·|M₁₂| + a₁₃·|M₁₃| Where Mᵢⱼ = Minor = 2×2 submatrix after deleting row i and column j Sign Pattern (cofactor signs): + − + − + − + − + Position (i,j) has sign (−1)^(i+j)

Key Properties of Determinants:

1. |Aᵀ| = |A| 2. If any row/column is all zeros → |A| = 0 3. Interchange two rows → determinant changes sign 4. Multiply a row by k → determinant multiplies by k 5. |kA| = kⁿ·|A| for n×n matrix 6. If two rows are identical → |A| = 0 7. Adding multiple of one row to another → |A| unchanged 8. |AB| = |A|·|B|
Worked Example — 3×3 Determinant

A = [[1,2,3],[4,5,6],[7,8,9]] |A| = 1·(5×9−6×8) − 2·(4×9−6×7) + 3·(4×8−5×7) = 1·(45−48) − 2·(36−42) + 3·(32−35) = 1·(−3) − 2·(−6) + 3·(−3) = −3 + 12 − 9 = 0 ← Singular! (rows are in AP)

📌 Adjoint and Inverse of a Matrix

Minor Mᵢⱼ: Delete row i and column j from matrix → determinant of remaining 2×2 submatrix.
Cofactor Cᵢⱼ: Cᵢⱼ = (−1)^(i+j) × Mᵢⱼ — same as minor but with sign adjustment.
Adjoint adj(A): Transpose of the cofactor matrix (i.e., replace each element by its cofactor, then transpose).
Inverse A⁻¹: Only exists when |A| ≠ 0. Formula: A⁻¹ = adj(A) / |A|

Quick formula for 2×2 inverse
If A = [[a,b],[c,d]], then A⁻¹ = (1/|A|)·[[d,−b],[−c,a]] Just swap main diagonal, negate off-diagonal, divide by determinant!
💡

Verify your inverse: Always check A·A⁻¹ = I. If you made an error in adj(A) or |A|, this check will catch it immediately. It takes 30 seconds and saves marks.

📌 System of Linear Equations — 3 Methods

Given 3 equations: a₁x+b₁y+c₁z=d₁, a₂x+b₂y+c₂z=d₂, a₃x+b₃y+c₃z=d₃

Method 1: Cramer's Rule (Fast & Clean) ⭐ Most Used
  1. Set up coefficient matrix A. Calculate Δ = |A|. If Δ=0, system has no unique solution.
  2. Form Δₓ by replacing column 1 (x-column) with the constant column [d₁,d₂,d₃]. Calculate Δₓ.
  3. Form Δᵧ by replacing column 2 (y-column) with constants. Calculate Δᵧ.
  4. Form Δᵤ by replacing column 3 (z-column) with constants. Calculate Δᵤ.
  5. Solutions: x = Δₓ/Δ, y = Δᵧ/Δ, z = Δᵤ/Δ
Method 2: Matrix Inversion (AX = B → X = A⁻¹B)
  1. Write in matrix form AX=B where A is coefficient matrix, X=[x,y,z]ᵀ, B=[d₁,d₂,d₃]ᵀ
  2. Find |A|. If |A|≠0, find adj(A), then A⁻¹ = adj(A)/|A|
  3. Multiply: X = A⁻¹·B. Each component gives the value of x, y, z
Method 3: Gauss-Jordan (Row Reduction to Reduced Row Echelon Form)
  1. Write augmented matrix [A|B] — a 3×4 matrix
  2. Using row operations (R₂→R₂−(a₂₁/a₁₁)R₁ etc.), create zeros below the first pivot (element [1,1])
  3. Create zeros below second pivot (element [2,2])
  4. Then eliminate UPWARD too: make zeros above each pivot (this is what makes it Gauss-JORDAN vs plain Gauss)
  5. Divide each row so each pivot = 1. The right side of [I|X] gives the solution directly.

📌 Partial Fractions — All 4 Cases

Partial fractions split a rational function P(x)/Q(x) [where degree(P) < degree(Q)] into simpler pieces that are easy to integrate or work with. First factor Q(x) completely.

Factor Type in Q(x)Partial Fraction Form
Non-repeated linear: (x−a)A/(x−a)
Repeated linear: (x−a)²A/(x−a) + B/(x−a)²
Repeated n times: (x−a)ⁿA₁/(x−a) + A₂/(x−a)² + … + Aₙ/(x−a)ⁿ
Non-repeated quadratic: (x²+px+q)(Ax+B)/(x²+px+q)
Repeated quadratic: (x²+px+q)²(Ax+B)/(x²+px+q) + (Cx+D)/(x²+px+q)²

Procedure: Write the partial fraction form, multiply both sides by the full denominator Q(x), substitute convenient values of x (roots of factors) to find constants. For irreducible quadratics, compare coefficients of equal powers of x.

Full Worked Example

Resolve (2x+1)/[(x−1)(x+2)(x−3)] into partial fractions. Write: (2x+1)/[(x−1)(x+2)(x−3)] = A/(x−1) + B/(x+2) + C/(x−3) Multiply both sides by (x−1)(x+2)(x−3): 2x+1 = A(x+2)(x−3) + B(x−1)(x−3) + C(x−1)(x+2) Put x=1: 3 = A(3)(−2) = −6A → A = −1/2 Put x=−2: −3 = B(−3)(−5) = 15B → B = −1/5 Put x=3: 7 = C(2)(5) = 10C → C = 7/10 Answer: −(1/2)/(x−1) − (1/5)/(x+2) + (7/10)/(x−3)

📌 Logarithms — Complete Theory

Definition: logₐN = x ⟺ aˣ = N. The base a must satisfy a>0, a≠1. N must be positive (log of 0 or negative is undefined in reals).

All Logarithm Properties
logₐ(mn) = logₐm + logₐn [Product → sum] logₐ(m/n) = logₐm − logₐn [Quotient → difference] logₐ(mⁿ) = n·logₐm [Power → coefficient] logₐa = 1 [Log of base = 1] logₐ1 = 0 [Log of 1 is always 0] logₐ(1/n) = −logₐn logₐm = logbm / logba [Change of base formula] log₁₀x ≡ log x (common logarithm, base 10) logₑx ≡ ln x (natural logarithm, base e, where e≈2.71828)
Exponential Function Properties
eˣ is strictly increasing; domain=all reals, range=(0,∞) e⁰=1, e¹=e, e⁻ˣ=1/eˣ ln(eˣ) = x and e^(lnx) = x [they are inverses] d/dx(eˣ) = eˣ [unique function that equals its own derivative!] ∫eˣdx = eˣ + C

📌 Compound Angle Formulas — The Foundation

Every multiple angle, half angle, product formula in trigonometry is derived from these six identities. If you know nothing else, know these.

sin(A+B) = sinA·cosB + cosA·sinB sin(A−B) = sinA·cosB − cosA·sinB cos(A+B) = cosA·cosB − sinA·sinB cos(A−B) = cosA·cosB + sinA·sinB tan(A+B) = (tanA+tanB)/(1−tanA·tanB) tan(A−B) = (tanA−tanB)/(1+tanA·tanB)
💡

Memory: sin(A±B) = "sin-cos ± cos-sin". cos(A+B) = "cos-cos ∓ sin-sin" — the ∓ means cos(A+B) subtracts but cos(A−B) adds.

📌 Multiple & Sub-Multiple Angle Formulas

Derived by setting B=A in compound angle formulas:

Double Angle Formulas (A+A = 2A)
sin 2A = 2 sinA cosA cos 2A = cos²A − sin²A = 1 − 2sin²A [use when you need sin²A: sin²A=(1−cos2A)/2] = 2cos²A − 1 [use when you need cos²A: cos²A=(1+cos2A)/2] tan 2A = 2tanA / (1−tan²A) Expressed in terms of t=tanA: sin 2A = 2t/(1+t²) cos 2A = (1−t²)/(1+t²) tan 2A = 2t/(1−t²)
Triple Angle Formulas
sin 3A = 3sinA − 4sin³A cos 3A = 4cos³A − 3cosA tan 3A = (3tanA − tan³A)/(1−3tan²A)
Half-Angle Formulas (set A=θ/2 in double angle)
sin²(θ/2) = (1−cosθ)/2 → sin(θ/2) = ±√[(1−cosθ)/2] cos²(θ/2) = (1+cosθ)/2 → cos(θ/2) = ±√[(1+cosθ)/2] tan(θ/2) = sinθ/(1+cosθ) = (1−cosθ)/sinθ

📌 Product-to-Sum & Sum-to-Product

Product → Sum (add or subtract compound angle formulas)
2sinA cosB = sin(A+B) + sin(A−B) 2cosA sinB = sin(A+B) − sin(A−B) 2cosA cosB = cos(A−B) + cos(A+B) 2sinA sinB = cos(A−B) − cos(A+B)
Sum → Product (replace A+B=C, A−B=D → A=(C+D)/2, B=(C−D)/2)
sinC + sinD = 2 sin((C+D)/2) cos((C−D)/2) sinC − sinD = 2 cos((C+D)/2) sin((C−D)/2) cosC + cosD = 2 cos((C+D)/2) cos((C−D)/2) cosC − cosD = −2 sin((C+D)/2) sin((C−D)/2)

📌 Properties of Triangles & Solution Methods

In triangle ABC, sides a,b,c are opposite to angles A,B,C respectively. All angles add to 180°.

Sine Rule: a/sinA = b/sinB = c/sinC = 2R (R=circumradius) Cosine Rule: a² = b²+c²−2bc·cosA → cosA = (b²+c²−a²)/2bc Tangent Rule: tan((A−B)/2) = ((a−b)/(a+b))·cot(C/2) Projection: a = b·cosC + c·cosB
GivenMethodSteps

📌 Inverse Trigonometric Functions

sin⁻¹x (arcsin) gives the angle whose sine is x. Domain: [−1,1]. Range: [−π/2, π/2].
cos⁻¹x: Domain: [−1,1]. Range: [0, π].
tan⁻¹x: Domain: all reals. Range: (−π/2, π/2).

Complementary pairs: sin⁻¹x + cos⁻¹x = π/2 tan⁻¹x + cot⁻¹x = π/2 sec⁻¹x + csc⁻¹x = π/2 Addition formulas: tan⁻¹x + tan⁻¹y = tan⁻¹[(x+y)/(1−xy)] when xy < 1 = π + tan⁻¹[(x+y)/(1−xy)] when xy > 1, x>0 2·tan⁻¹x = sin⁻¹(2x/(1+x²)) = cos⁻¹((1−x²)/(1+x²))

📌 Hyperbolic Functions

sinh x = (eˣ−e⁻ˣ)/2 cosh x = (eˣ+e⁻ˣ)/2 tanh x = sinh x/cosh x sech x = 1/cosh x coth x = cosh x/sinh x csch x = 1/sinh x Fundamental Identity: cosh²x − sinh²x = 1 Other identities: 1 − tanh²x = sech²x coth²x − 1 = csch²x Derivatives: d/dx(sinh x) = cosh x, d/dx(cosh x) = sinh x d/dx(tanh x) = sech²x

📌 Complex Numbers — From Basics to Euler Form

A complex number z = a+ib where i=√(−1). Note: i²=−1, i³=−i, i⁴=1 (cycles with period 4). Real part Re(z)=a, Imaginary part Im(z)=b.

Arithmetic: (a+ib)+(c+id) = (a+c)+i(b+d) (a+ib)−(c+id) = (a−c)+i(b−d) (a+ib)(c+id) = (ac−bd)+i(ad+bc) [use i²=−1] (a+ib)/(c+id) = [(a+ib)(c−id)]/[(c+id)(c−id)] = [(ac+bd)+i(bc−ad)]/(c²+d²) Conjugate: z̄ = a−ib; z·z̄ = a²+b² = |z|² Modulus: |z| = r = √(a²+b²) Argument: θ = arg(z) = tan⁻¹(b/a) [adjust for correct quadrant!] Polar Form: z = r(cosθ+i sinθ) where r=|z|, θ=arg(z) Euler Form: z = r·e^(iθ) [since e^(iθ)=cosθ+i sinθ]
De Moivre's Theorem (Critical for Exam)
(cosθ + i sinθ)ⁿ = cos(nθ) + i sin(nθ) Equivalently: (e^(iθ))ⁿ = e^(inθ) Application — nth roots of unity: zⁿ=1 has n roots: e^(i·2kπ/n), k=0,1,2,...,n−1 These are equally spaced on unit circle in Argand plane.
Example: Multiplication in Polar Form

z₁=2(cos60°+isin60°), z₂=3(cos30°+isin30°) z₁·z₂ = 2×3 [cos(60°+30°)+isin(60°+30°)] = 6[cos90°+isin90°] = 6[0+i·1] = 6i Key: Multiply moduli, Add arguments. For division: divide moduli, subtract arguments.

📌 Straight Lines — Every Form You Need

The slope (m) of a line is tan θ where θ is the angle it makes with the positive x-axis. m = (y₂−y₁)/(x₂−x₁). Slope encodes direction: positive slope → rising line, negative → falling line, zero → horizontal, undefined → vertical.

Slope-intercept: y = mx + c [m=slope, c=y-intercept] Point-slope: y−y₁ = m(x−x₁) [given slope + one point] Two-point form: (y−y₁)/(y₂−y₁) = (x−x₁)/(x₂−x₁) Intercept form: x/a + y/b = 1 [a=x-intercept, b=y-intercept] Normal form: x cosα + y sinα = p [p=perp. distance from origin] General form: ax + by + c = 0
Distance, Angle, and Parallel/Perpendicular Conditions
Perpendicular distance from (x₁,y₁) to line ax+by+c=0: d = |ax₁+by₁+c| / √(a²+b²) Angle θ between lines with slopes m₁ and m₂: tan θ = |(m₁−m₂)/(1+m₁m₂)| Parallel lines: m₁ = m₂ (equal slopes) Perpendicular: m₁×m₂ = −1 (product of slopes = −1) Distance between parallel lines ax+by+c₁=0 and ax+by+c₂=0: d = |c₁−c₂| / √(a²+b²)

📌 Circles — All Forms and Tangent/Normal

Standard form (centre h,k; radius r): (x−h)² + (y−k)² = r² General form: x²+y²+2gx+2fy+c = 0 Centre = (−g, −f) Radius = √(g²+f²−c) Diameter form (endpoints of diameter (x₁,y₁) and (x₂,y₂)): (x−x₁)(x−x₂) + (y−y₁)(y−y₂) = 0 Condition for general equation to be a real circle: g²+f²−c > 0
Tangent and Normal to Circle x²+y²=r² at point (x₁,y₁)
Tangent: x·x₁ + y·y₁ = r² Normal: y/x = y₁/x₁ → passes through centre (0,0) For general circle x²+y²+2gx+2fy+c=0 at (x₁,y₁): Tangent: x·x₁+y·y₁+g(x+x₁)+f(y+y₁)+c = 0 Condition for line y=mx+c to touch circle x²+y²=r²: c² = r²(1+m²) → c = ±r√(1+m²)

📌 The Concept of Differentiation

The derivative of y=f(x) at a point x is defined as: dy/dx = lim(h→0) [f(x+h)−f(x)]/h. Geometrically it is the slope of the tangent to the curve at that point. Physically it is the instantaneous rate of change. A function is differentiable at x if this limit exists.

📌 All Standard Derivatives (Must Memorize)

Algebraic: d/dx(xⁿ) = nxⁿ⁻¹ d/dx(√x) = 1/(2√x) d/dx(1/x) = −1/x² d/dx(c) = 0 Exponential & Log: d/dx(eˣ) = eˣ d/dx(aˣ) = aˣ·ln a d/dx(ln x) = 1/x d/dx(logₐx) = 1/(x·ln a) Trigonometric: d/dx(sin x) = cos x d/dx(cos x) = −sin x d/dx(tan x) = sec²x d/dx(cot x) = −csc²x d/dx(sec x) = sec x·tan x d/dx(csc x) = −csc x·cot x Inverse Trigonometric: d/dx(sin⁻¹x) = 1/√(1−x²) d/dx(cos⁻¹x) = −1/√(1−x²) d/dx(tan⁻¹x) = 1/(1+x²) d/dx(cot⁻¹x) = −1/(1+x²) d/dx(sec⁻¹x) = 1/(|x|√(x²−1)) Hyperbolic: d/dx(sinh x) = cosh x d/dx(cosh x) = sinh x d/dx(tanh x) = sech²x d/dx(coth x) = −csch²x

📌 Rules of Differentiation

Sum/Difference Rule: (f±g)' = f'±g' Product Rule: (uv)' = u'v + uv' ← "UV formula" Quotient Rule: (u/v)' = (u'v−uv')/v² ← "VdU−UdV over V²" Chain Rule: d/dx[f(g(x))] = f'(g(x))·g'(x) dy/dx = (dy/du)·(du/dx)
Chain Rule Examples

① d/dx[sin(x²)] = cos(x²)·2x = 2x·cos(x²) ② d/dx[e^(3x+1)] = e^(3x+1)·3 = 3e^(3x+1) ③ d/dx[ln(sin x)] = (1/sin x)·cos x = cot x ④ d/dx[(x²+1)⁵] = 5(x²+1)⁴·2x = 10x(x²+1)⁴

📌 Implicit Differentiation

When y is defined implicitly by an equation like F(x,y)=0, differentiate both sides w.r.t. x. Every term with y requires chain rule: d/dx[f(y)] = f'(y)·(dy/dx). Collect all dy/dx terms on one side and solve.

Example

Find dy/dx for x²+y²=25 (circle of radius 5) Differentiate: 2x + 2y·(dy/dx) = 0 Solve: dy/dx = −x/y [slope of tangent to circle at any point] At point (3,4): dy/dx = −3/4 ← tangent slope at that point.

📌 Parametric Differentiation

When both x and y are functions of a parameter t: x=f(t), y=g(t), use dy/dx = (dy/dt)÷(dx/dt).

For second derivative: d²y/dx² = [d/dt(dy/dx)] / (dx/dt). Important: do NOT just square dy/dx.

Example — Cycloid

x = a(t−sin t), y = a(1−cos t) dx/dt = a(1−cos t), dy/dt = a·sin t dy/dx = a·sin t / [a(1−cos t)] = sin t/(1−cos t) Using half-angle: = 2sin(t/2)cos(t/2) / 2sin²(t/2) = cos(t/2)/sin(t/2) = cot(t/2)

📌 Logarithmic Differentiation

Used for functions of the form y = [f(x)]^g(x) (variable in both base and exponent), or products/quotients of many functions. Take ln of both sides first, then differentiate.

Example

Find dy/dx for y = xˢⁱⁿˣ Take ln: ln y = sin x · ln x Differentiate: (1/y)·dy/dx = cos x·ln x + sin x·(1/x) dy/dx = y·[cos x·ln x + sin x/x] = xˢⁱⁿˣ·[cos x·ln x + sin x/x]

📌 Applications — Tangent, Normal, Increasing/Decreasing

Tangent at (x₁,y₁) on y=f(x): m = f'(x₁) Equation: y−y₁ = m(x−x₁) Normal at (x₁,y₁): slope = −1/m (perpendicular to tangent) Equation: y−y₁ = (−1/m)(x−x₁) Increasing function: f'(x) > 0 in that interval Decreasing function: f'(x) < 0 in that interval Rate of change: if y=f(t), dy/dt is rate of change at time t

📌 Maxima & Minima — Second Derivative Test

Complete Procedure
  1. Find dy/dx (first derivative). Set dy/dx = 0. Solve for x. These are critical points.
  2. Find d²y/dx² (second derivative).
  3. For each critical point x=c: If d²y/dx²|ₓ₌꜀ < 0 → Local Maximum; if > 0 → Local Minimum; if = 0 → inconclusive.
  4. Maximum value = f(c) at max critical point. Minimum value = f(c) at min critical point.
Full Example

f(x) = x³ − 6x² + 9x + 2 f'(x) = 3x²−12x+9 = 3(x²−4x+3) = 3(x−1)(x−3) = 0 Critical points: x=1 and x=3 f''(x) = 6x−12 At x=1: f''(1) = 6−12 = −6 < 0 → Local MAXIMUM; f(1)=1−6+9+2=6 At x=3: f''(3) = 18−12 = 6 > 0 → Local MINIMUM; f(3)=27−54+27+2=2

📌 Partial Differentiation & Euler's Theorem

For z=f(x,y), the partial derivative ∂z/∂x means differentiate w.r.t. x treating y as a constant — as if y is just another number coefficient. ∂z/∂y treats x as constant.

If z = x³y² + 2x²y + 5xy³ ∂z/∂x = 3x²y² + 4xy + 5y³ (differentiate each term, treat y as constant) ∂z/∂y = 2x³y + 2x² + 15xy² (differentiate each term, treat x as constant) Second-order partials: ∂²z/∂x² = 6xy² + 4y ∂²z/∂y² = 2x³ + 30xy ∂²z/∂x∂y = 6x²y + 4x + 15y² (mixed — differentiate ∂z/∂x w.r.t. y) Note: ∂²z/∂x∂y = ∂²z/∂y∂x always (Clairaut's theorem)
Euler's Theorem for Homogeneous Functions
f(x,y) is HOMOGENEOUS of degree n if f(tx,ty) = tⁿ·f(x,y) Examples: x²+xy+y² is degree 2; x³+x²y is degree 3; x/y is degree 0 EULER'S THEOREM: If f is homogeneous of degree n, then: x·∂f/∂x + y·∂f/∂y = n·f Extended version (second-order): x²·∂²f/∂x² + 2xy·∂²f/∂x∂y + y²·∂²f/∂y² = n(n−1)·f
Euler's Theorem Example

Verify for f(x,y) = x²+2xy+y² (homogeneous, degree 2) ∂f/∂x = 2x+2y, ∂f/∂y = 2x+2y x·∂f/∂x + y·∂f/∂y = x(2x+2y) + y(2x+2y) = 2x²+2xy + 2xy+2y² = 2(x²+2xy+y²) = 2f ✓ (n=2)

📌 Integration — The Concept

Integration is the reverse of differentiation. ∫f(x)dx = F(x)+C means F'(x)=f(x). The constant C is the constant of integration — it appears because differentiating a constant gives zero, so the "antiderivative" is not unique. The integral is also the area under the curve from a geometrical perspective.

📌 Standard Integrals Master Table

∫xⁿ dx = xⁿ⁺¹/(n+1) + C (n ≠ −1) ∫1/x dx = ln|x| + C ∫eˣ dx = eˣ + C ∫aˣ dx = aˣ/ln a + C ∫sin x dx = −cos x + C ∫cos x dx = sin x + C ∫tan x dx = ln|sec x| + C (=−ln|cos x|+C) ∫cot x dx = ln|sin x| + C ∫sec x dx = ln|sec x + tan x| + C ∫csc x dx = ln|csc x − cot x| + C ∫sec²x dx = tan x + C ∫csc²x dx = −cot x + C ∫sec x tan x dx = sec x + C ∫csc x cot x dx = −csc x + C ∫1/(x²+a²) dx = (1/a)·tan⁻¹(x/a) + C ∫1/√(a²−x²) dx = sin⁻¹(x/a) + C ∫1/√(x²+a²) dx = ln|x+√(x²+a²)| + C ∫1/(x²−a²) dx = (1/2a)·ln|(x−a)/(x+a)| + C ∫√(a²−x²) dx = (x/2)√(a²−x²) + (a²/2)sin⁻¹(x/a) + C

📌 Integration by Substitution

The key insight: if you see a function and its derivative (or a multiple of it) in the same integrand, substitution converts it to a standard form. Let u = inner function → du = derivative·dx → solve for dx → substitute everything → integrate w.r.t. u → back-substitute.

Multiple Examples

① ∫2x(x²+1)⁷ dx: Let u=x²+1, du=2x dx = ∫u⁷ du = u⁸/8 + C = (x²+1)⁸/8 + C ② ∫sin³x·cos x dx: Let u=sin x, du=cos x dx = ∫u³ du = u⁴/4 + C = sin⁴x/4 + C ③ ∫eˢⁱⁿˣ·cos x dx: Let u=sin x, du=cos x dx = ∫eᵘ du = eᵘ + C = e^(sin x) + C ④ ∫tan x dx = ∫sin x/cos x dx: Let u=cos x, du=−sin x dx = ∫−1/u du = −ln|u| + C = −ln|cos x| + C = ln|sec x| + C

📌 Integration by Parts — ILATE Rule

Formula: ∫u dv = uv − ∫v du. The ILATE order tells you which function to take as 'u':
Inverse trig (sin⁻¹x, tan⁻¹x) → Log (ln x) → Algebraic (xⁿ) → Trig (sin x, cos x) → Exponential (eˣ)
Pick the one that comes earlier in ILATE as u. The remaining part is dv.

Integration by Parts Examples

① ∫x·sin x dx: (A before T) → u=x, dv=sin x dx du=dx, v=−cos x = x(−cos x) − ∫(−cos x) dx = −x cos x + sin x + C ② ∫x²·eˣ dx: (A before E) → u=x², dv=eˣ dx du=2x dx, v=eˣ = x²eˣ − ∫2x eˣ dx [apply parts again to ∫xeˣ] = x²eˣ − 2(xeˣ−eˣ) + C = eˣ(x²−2x+2) + C ③ ∫eˣ·sin x dx: (E and T — either order works but leads to solve by recurrence) Let I = ∫eˣ sin x dx; u=sin x, dv=eˣ dx → v=eˣ, du=cos x dx I = eˣ sin x − ∫eˣ cos x dx For ∫eˣ cos x dx: u=cos x, dv=eˣ dx → = eˣcos x + ∫eˣsin x dx = eˣcos x + I So: I = eˣ sin x − (eˣcos x + I) → 2I = eˣ(sin x−cos x) I = eˣ(sin x−cos x)/2 + C

📌 Definite Integrals & Key Properties

∫ₐᵇ f(x)dx = F(b)−F(a) [Fundamental Theorem of Calculus] Properties: P1: ∫ₐᵃ f(x)dx = 0 P2: ∫ₐᵇ f(x)dx = −∫ᵦₐ f(x)dx P3: ∫ₐᵇ f(x)dx = ∫ₐᶜ f(x)dx + ∫ᶜᵇ f(x)dx P4 (King): ∫ₐᵇ f(x)dx = ∫ₐᵇ f(a+b−x)dx ← VERY USEFUL for simplification P5: ∫₀ᵃ f(x)dx = ∫₀ᵃ f(a−x)dx P6: ∫₋ₐᵃ f(x)dx = 2∫₀ᵃ f(x)dx if f is EVEN; = 0 if f is ODD

📌 Areas and Volumes of Revolution

Area between curve y=f(x) and x-axis from x=a to x=b: A = ∫ₐᵇ |f(x)| dx If curve is entirely above x-axis: A = ∫ₐᵇ f(x) dx Area between two curves f(x) and g(x) [f(x)≥g(x)] from a to b: A = ∫ₐᵇ [f(x)−g(x)] dx Volume of solid of revolution about x-axis (Disk Method): V = π∫ₐᵇ [y]² dx = π∫ₐᵇ [f(x)]² dx Volume about y-axis: V = π∫ᶜᵈ [x]² dy = π∫ᶜᵈ [g(y)]² dy Volume between two curves (Washer Method): V = π∫ₐᵇ {[f(x)]²−[g(x)]²} dx

📌 Mean, RMS Values & Numerical Methods

Mean (Average) Value of f(x) over [a,b]: f̄ = (1/(b−a)) · ∫ₐᵇ f(x) dx RMS (Root Mean Square) Value: f_rms = √[ (1/(b−a))·∫ₐᵇ {f(x)}² dx ] Note: For current in AC circuits, RMS = Peak/√2 for sinusoidal waves
Trapezoidal Rule — h=(b−a)/n, yᵢ=f(a+i·h)
∫ₐᵇ f(x)dx ≈ (h/2)[y₀ + 2y₁ + 2y₂ + ... + 2yₙ₋₁ + yₙ] = (h/2)[First + Last + 2×(all middle terms)] Simpson's 1/3 Rule — n must be EVEN: ∫ₐᵇ f(x)dx ≈ (h/3)[y₀ + 4y₁ + 2y₂ + 4y₃ + 2y₄ + ... + 4yₙ₋₁ + yₙ] Pattern: 1, 4, 2, 4, 2, 4, ..., 4, 1 Coefficients: 1 and 1 for endpoints; 4 for odd-indexed; 2 for even-indexed middle Simpson's is MORE ACCURATE than Trapezoidal for smooth functions.

Differential Equations

▼

📌 Basics — Order, Degree, Formation

A Differential Equation (DE) involves derivatives of an unknown function. Order = the highest derivative in the equation. Degree = the power of the highest-order derivative (after clearing radicals and fractions involving derivatives).

dy/dx = x²+y → Order 1, Degree 1 d²y/dx² + 4dy/dx + y = 0 → Order 2, Degree 1 (d²y/dx²)² + dy/dx = x → Order 2, Degree 2 √(dy/dx) = x → degree ambiguous until squared: dy/dx=x² → Order 1, Degree 1

Formation: Eliminate arbitrary constants from a family of curves to form a DE. If n arbitrary constants → nth order DE needed.

📌 Variable Separable Method

A DE of the form dy/dx = f(x)·g(y) can be separated: dy/g(y) = f(x)dx. Integrate both sides separately.

Examples

① Solve: dy/dx = xy Separate: dy/y = x dx Integrate: ln|y| = x²/2 + C₁ → y = Ae^(x²/2) where A=e^C₁ ② Solve: (1+x²)dy = xy dx Separate: dy/y = x/(1+x²) dx Integrate: ln|y| = (1/2)ln(1+x²) + C y = A·√(1+x²)

📌 Homogeneous Equations

A DE dy/dx = f(x,y) is homogeneous if f(tx,ty)=f(x,y) — i.e., f is degree 0, meaning it depends only on y/x. Substitute v=y/x (so y=vx, dy/dx=v+x·dv/dx). This always converts to a separable equation.

Homogeneous Example

Solve: dy/dx = (x²+y²)/(2xy) Check homogeneity: f(tx,ty)=(t²x²+t²y²)/(2·tx·ty) = (x²+y²)/(2xy) = f(x,y) ✓ degree 0 Substitute y=vx → dy/dx = v+x·dv/dx v+x·dv/dx = (x²+v²x²)/(2x·vx) = (1+v²)/(2v) x·dv/dx = (1+v²)/(2v) − v = (1+v²−2v²)/(2v) = (1−v²)/(2v) Separate: 2v/(1−v²) dv = dx/x −ln|1−v²| = ln|x| + C 1−v² = A/x → 1−y²/x² = A/x → x²−y² = Ax (general solution)

📌 Linear First-Order DE: dy/dx + Py = Q

This is the most important 1st-order type. The Integrating Factor (IF) = e^(∫P dx). Multiplying the equation by IF converts the LHS into d/dx[y·IF].

Complete Solution Formula
Given: dy/dx + P(x)·y = Q(x) IF = e^(∫P dx) y·(IF) = ∫[Q·(IF)] dx + C
Linear DE Full Solution

Solve: dy/dx − y/x = x² Here P = −1/x, Q = x² IF = e^(∫−1/x dx) = e^(−ln x) = e^(ln(1/x)) = 1/x Multiply: (1/x)dy/dx − y/x² = x LHS = d/dx[y·(1/x)] → integrate both sides: y/x = ∫x dx = x²/2 + C y = x³/2 + Cx

📌 Bernoulli's Equation

Form: dy/dx + Py = Qyⁿ (n≠0,1). Divide by yⁿ and substitute v = y^(1−n) to convert to linear DE.

Substitution: v = y^(1−n) dv/dx = (1−n)·y^(−n)·dy/dx After substitution: (1/(1−n))·dv/dx + Pv = Q i.e., dv/dx + (1−n)P·v = (1−n)Q ← this is a LINEAR DE in v

📌 Second-Order Linear DE with Constant Coefficients

Form: ay'' + by' + cy = f(x). General solution = CF + PI (Complementary Function + Particular Integral).

Finding CF via Auxiliary Equation
  1. Write the Auxiliary Equation (AE): am²+bm+c = 0
  2. Solve for m using the quadratic formula: m = [−b±√(b²−4ac)]/(2a)
  3. Case 1 — Real distinct roots m₁≠m₂: CF = C₁e^(m₁x) + C₂e^(m₂x)
  4. Case 2 — Equal roots m₁=m₂=m: CF = (C₁+C₂x)e^(mx)
  5. Case 3 — Complex roots m=α±iβ: CF = e^(αx)[C₁cos(βx)+C₂sin(βx)]
PI Rules — Symbolic Operator Method (D≡d/dx)
For f(D)y = eᵃˣ: PI = eᵃˣ/f(a) if f(a)≠0 PI = x·eᵃˣ/f'(a) if f(a)=0 (first failure) For f(D)y = sin(ax) or cos(ax): Replace D² by −a²: PI = sin(ax)/f(−a²) or cos(ax)/f(−a²) If denominator=0 → multiply numerator by x and divide by derivative of denominator For f(D)y = xⁿ (polynomial): PI = [f(D)]⁻¹·xⁿ Expand (1+D)⁻¹ = 1−D+D²−D³+... using binomial, operate term by term Each Dᵏ·xⁿ = n!/(n−k)!·xⁿ⁻ᵏ (i.e., differentiate k times) For eᵃˣ·V(x): PI = eᵃˣ·[f(D+a)]⁻¹·V(x) [Exponential Shift Theorem]
Full 2nd Order DE Example

Solve: y'' − 3y' + 2y = e^(4x) AE: m²−3m+2=0 → (m−1)(m−2)=0 → m=1,2 (real distinct) CF = C₁eˣ + C₂e^(2x) PI: f(D)=D²−3D+2; R=e^(4x); substitute D=4: f(4)=16−12+2=6 PI = e^(4x)/6 General Solution: y = C₁eˣ + C₂e^(2x) + e^(4x)/6

📌 What is the Laplace Transform?

The Laplace Transform converts a time-domain function f(t) into a complex-frequency-domain function F(s): L{f(t)} = F(s) = ∫₀^∞ e^(−st)·f(t) dt. Its power: it turns differential equations into algebraic equations, which are far easier to solve. After solving algebraically, take the Inverse Laplace Transform to get back the time-domain answer.

📌 Standard LT Table

L{1} = 1/s (s>0) L{t} = 1/s² L{tⁿ} = n!/s^(n+1) (n is positive integer) L{eᵃᵗ} = 1/(s−a) (s>a) L{e⁻ᵃᵗ} = 1/(s+a) L{sin at} = a/(s²+a²) L{cos at} = s/(s²+a²) L{sinh at} = a/(s²−a²) L{cosh at} = s/(s²−a²) L{t sin at} = 2as/(s²+a²)² L{t cos at} = (s²−a²)/(s²+a²)²

📌 Properties of Laplace Transforms

Linearity: L{af(t)+bg(t)} = aF(s)+bG(s) First Shifting (s-shift): L{eᵃᵗ f(t)} = F(s−a) ← just replace s by (s−a) in F(s) Change of Scale: L{f(at)} = (1/a)·F(s/a) Multiplication by t: L{t·f(t)} = −d/ds[F(s)] = −F'(s) L{tⁿf(t)} = (−1)ⁿ·dⁿF(s)/dsⁿ Division by t: L{f(t)/t} = ∫ₛ^∞ F(u) du (improper integral) Derivatives: L{f'(t)} = sF(s) − f(0) L{f''(t)} = s²F(s) − s·f(0) − f'(0) L{f'''(t)} = s³F(s) − s²f(0) − s·f'(0) − f''(0) Integrals: L{∫₀ᵗ f(u)du} = F(s)/s

📌 Unit Step Function & Second Shifting

Heaviside Unit Step: u(t−a) = 0 for t < a; u(t−a) = 1 for t ≥ a LT of unit step: L{u(t−a)} = e^(−as)/s Second Shifting Theorem: L{f(t−a)·u(t−a)} = e^(−as)·F(s) Inverse: L⁻¹{e^(−as)·F(s)} = f(t−a)·u(t−a)

📌 Inverse LT & Convolution Theorem

To find L⁻¹{F(s)}: Step 1: Decompose F(s) using partial fractions into recognizable terms Step 2: Apply ILT to each term using standard table Key ILT results: L⁻¹{1/s} = 1, L⁻¹{1/s²} = t, L⁻¹{n!/s^(n+1)} = tⁿ L⁻¹{1/(s−a)} = eᵃᵗ L⁻¹{a/(s²+a²)} = sin at, L⁻¹{s/(s²+a²)} = cos at Convolution: (f*g)(t) = ∫₀ᵗ f(τ)·g(t−τ) dτ Convolution Theorem: L{f*g} = F(s)·G(s) Inverse form: L⁻¹{F(s)·G(s)} = f(t)*g(t)
Solving Initial Value Problems (IVP) with Laplace
  1. Take LT of both sides of the DE. Use L{y''} = s²Y−sy(0)−y'(0), L{y'} = sY−y(0), L{y} = Y(s). Substitute given initial conditions.
  2. Collect all Y(s) terms. Solve algebraically for Y(s).
  3. Simplify Y(s) using partial fractions.
  4. Take inverse LT of each term. The result y(t) is the particular solution (already satisfying initial conditions!).

📌 What is a Fourier Series?

Any periodic function f(x) with period 2π can be expressed as an infinite series of sines and cosines: f(x) = a₀/2 + Σ[aₙcos(nx) + bₙsin(nx)]. This is like decomposing a complex wave into fundamental frequencies — which is why it's used in signal processing, electronics, and heat transfer. The Euler formulas give you the coefficients.

📌 Euler's Coefficient Formulas

For period 2π over interval (C, C+2π)
f(x) = a₀/2 + Σₙ₌₁^∞ [aₙcos(nx) + bₙsin(nx)] a₀ = (1/π)∫_C^(C+2π) f(x) dx aₙ = (1/π)∫_C^(C+2π) f(x)·cos(nx) dx (n = 1,2,3,...) bₙ = (1/π)∫_C^(C+2π) f(x)·sin(nx) dx (n = 1,2,3,...) Most common interval: (−π, π) or (0, 2π)

📌 Even & Odd Functions — Shortcut

Even function: f(−x) = f(x) — symmetric about y-axis. The product of two even functions is even; even × odd = odd.
Odd function: f(−x) = −f(x) — antisymmetric about origin.

For EVEN function on (−π, π): All bₙ = 0 (no sine terms). f(x) = a₀/2 + Σaₙcos(nx) a₀ = (2/π)∫₀^π f(x) dx aₙ = (2/π)∫₀^π f(x)·cos(nx) dx For ODD function on (−π, π): a₀=0, all aₙ=0 (no cosine terms). f(x) = Σbₙsin(nx) bₙ = (2/π)∫₀^π f(x)·sin(nx) dx

📌 Half-Range Series

When f(x) is only defined on (0,π), you can choose to extend it as even or odd, giving two different series:

Half-range COSINE series (extend as even function): f(x) = a₀/2 + Σaₙcos(nx) a₀ = (2/π)∫₀^π f(x) dx aₙ = (2/π)∫₀^π f(x)·cos(nx) dx Half-range SINE series (extend as odd function): f(x) = Σbₙsin(nx) bₙ = (2/π)∫₀^π f(x)·sin(nx) dx
💡

Famous result from Fourier series: Expanding f(x)=x on (−π,π) and evaluating at x=π/2 gives: π/4 = 1 − 1/3 + 1/5 − 1/7 + ... (Leibniz formula). Expanding f(x)=x² and using Parseval's identity gives π²/6 = 1 + 1/4 + 1/9 + ... (Basel problem). These are classic ECET exam questions!
